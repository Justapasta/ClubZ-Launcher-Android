# Club Z — Launcher para celular (Android)

Launcher de Minecraft Java para Android hecho para el servidor **Club Z**.
Al abrirlo instala solo el modpack de Club Z para celular (con NeoForge) y deja todo listo para entrar directo al servidor.

## Descargar

- **APK (celulares de 64 bits, casi todos):** http://194.163.149.70:8090/launcher/movil/ClubZ-Celular.apk
- Requisitos: Android 8 o más nuevo y **6 GB de RAM o más** (el modpack es grande).

## Cómo se usa

1. Instala el APK (Android te va a pedir permitir "instalar apps de origen desconocido").
2. Ábrelo: descarga e instala el modpack de Club Z la primera vez (tarda unos minutos, mejor con WiFi).
3. Agrega tu cuenta y dale a **Jugar**: entra directo al servidor.

## Qué trae

- Solo los mods que el servidor necesita, más unos pocos de rendimiento (Sodium, Entity Culling, CreateClub Optimized).
- Club Z Core detecta que juegas desde el celular: pone opciones livianas la primera vez y te marca con ✆ en el servidor.
- Se actualiza solo cuando el modpack cambia.
